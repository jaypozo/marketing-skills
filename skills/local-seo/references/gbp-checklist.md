# Business profile checklist

Work through it field by field. Fill the "Current" column first, then decide on changes. Google changes which features are available fairly often, so if a field below doesn't exist any more, skip it.

| Field | Check | Current | Change |
| --- | --- | --- | --- |
| Business name | Exactly as on signage, vehicles and legal documents. No towns, services or slogans added. | | |
| Primary category | Matches what most customers search for. Compare with the top three competitors in the map pack. A change can trigger re-verification. | | |
| Secondary categories | Only services the business provides, and only terms it's allowed to use (some professions limit words like "specialist"). Remove any that don't fit. | | |
| Address or service area | Storefront: the exact address, matching the website. Service area: address hidden, the towns or regions listed. | | |
| Phone | Main local number, or a tracking number as primary with the main number as an additional one | | |
| Website link | The most relevant page (homepage or location page), with a UTM tag | | |
| Hours | Regular hours correct. Holiday hours set in advance. | | |
| Services | Every service listed, with a one-line description in the customer's words and a price where sensible | | |
| Products | Skip unless the business sells items: main products with photos and prices | | |
| Description | What the business does, for whom and where, in plain language. No links, no keyword lists. | | |
| Photos | Exterior (so people recognize it on arrival), interior, team, work, vehicles. Real photos, not stock. Add some every month. | | |
| Attributes | Accessibility, payment options, languages, insurance or booking options and similar, where accurate | | |
| Booking or quote link | Points to a working form or booking page | | |
| Reviews | Count, average, date of the newest, share with replies | | |
| Updates or posts | Optional. Use them for real offers, events or recent work. | | |
| Suggested edits | Check for edits from the public or Google, and correct any that are wrong | | |

## Monthly upkeep

- Add 3 to 5 new photos.
- Reply to every new review.
- Check for suggested edits and changes to hours or categories.
- Update holiday hours for the coming month.
- Note profile calls, direction requests and website clicks against the previous month.

## Other listings to keep consistent

Apple Business Connect (Apple Maps), Bing Places (it can import the Google profile), Facebook, the data aggregators that feed smaller sites, the main directories for the trade, the local chamber of commerce or trade association, and any booking platform the business uses. Keep them identical to the profile on name, address and phone.

Practitioners (doctors, dentists, lawyers, agents) can have their own listings beside the practice's. Check for these, and keep their details consistent, so reviews don't split across duplicates.
