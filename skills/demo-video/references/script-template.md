# Script template and recording setup

## Script structure

| Part | Time (for a 3-minute video) | What happens |
| --- | --- | --- |
| Result first | 0:00 to 0:10 | Show the finished outcome on screen. One sentence on who this is for and what they'll be able to do. |
| Setup | 0:10 to 0:30 | What the viewer needs before starting: account, file, device, five minutes. |
| Steps | 0:30 to 2:30 | Each step done live. Say what you're clicking and what it does for the viewer. One step per sentence or two. |
| Result again | 2:30 to 2:45 | Show the outcome produced by the steps just shown. |
| Next step | 2:45 to 3:00 | One action and why it's useful now, said once. The same link goes in the description and on the end screen. |

For longer tutorials, keep the same parts and add chapters at each step.

Write narration for the ear:

- Short sentences. Say "click Export" rather than "proceed to export your file".
- Name things exactly as they appear on screen.
- Say why before how when a step looks strange ("we set this to manual so it doesn't overwrite your old photos").
- Count the words: about 150 spoken words is one minute. Then add the seconds of silent screen action (loading, typing) to the timing column.

Blank two-column script:

```markdown
| Time | VISUAL | AUDIO |
| --- | --- | --- |
| 0:00 | | |
| 0:06 | | |
```

## Screen recording setup

- [ ] Demo account filled with realistic made-up data. No real customer names, emails or numbers.
- [ ] Notifications, chat apps and calendar alerts turned off. Browser bookmarks bar hidden.
- [ ] Screen resolution set so text is large. Record at 1080p or higher.
- [ ] Cursor enlarged or highlighted. Clicks shown if the recorder supports it.
- [ ] Browser zoom at 110% to 125% for web apps.
- [ ] The path run through once before recording, so nothing loads for the first time on camera.

## Camera and sound setup

For noisy places (kitchens, shops, workshops), record narration separately at a desk and use the location footage as pictures under it.

- [ ] Face the light source: a window or one soft light at about 45 degrees. No bright window behind the speaker.
- [ ] Microphone within about 30 cm of the mouth, or a clip-on mic on the chest.
- [ ] Room with soft furnishings (rug, curtains, sofa). Bare rooms echo.
- [ ] Fridge, fans and heaters off if they can be heard.
- [ ] 20-second test recorded and played back on headphones.
- [ ] Phone or camera on a stand at eye level, held horizontal for the main video. Get a separate vertical take if the cut-downs need a talking head.
- [ ] Setup written down (light position, mic, camera height) so the next video matches.

## Edit pass

1. Assemble the steps in script order. Remove mistakes, long pauses and "um" at the start of sentences.
2. Fix obvious sound and color differences between takes.
3. Zoom or crop wherever interface text is small.
4. Add captions and check the product names in them.
5. Music, if any, sits well under the voice: you should have to strain to hear it.
6. Watch once on a phone at normal speed without pausing. Note every moment you lose track.
